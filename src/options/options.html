Slyfox settings

Slyfox sends the terms on a page to Sarvam AI with your own API key. The key is stored on this device only.

Get a key from the Sarvam dashboard.

Slyfox checks that your key can use the model before saving.

Applies to the main analysis. Higher levels can catch more but are slower, and reasoning is billed as output tokens.

Langfuse tracing

Optional. Sends a trace of each analysis to your own Langfuse project: timings, token usage and errors, plus the prompts and responses if you allow it. Page text is scrubbed of personal details before it is traced.

Your Langfuse Cloud region, or the address of your self-hosted Langfuse.

Create both under Settings → API Keys in your Langfuse project. They are stored on this device and sent only to the host above.

Turn off to send only timings, token counts and errors.
